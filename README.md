# Personal Finance Agents

## Getting started

```bash
git clone https://github.com/vaibhavkapur/Personal-Finance-Agents.git
cd Personal-Finance-Agents/projects/Personal-Banker
```

Follow the selected project's README from that directory. References to the “repository root” in imported project documentation mean that project's directory here. When older guides show a standalone clone command, use the master clone above and enter the corresponding project directory instead.

Install dependencies and run applications independently inside each project. Point deployment tools at the relevant `projects/<name>` directory. These applications use synthetic fixtures and mock providers; consult each project's documentation for its execution limits.

- [Refund-and-Fee-Recovery-Agent](projects/Refund-and-Fee-Recovery-Agent/) — Refund recovery, issuer disputes, and independent credit verification.
- [Loan-Negotiation-Agent](projects/Loan-Negotiation-Agent/) — Mortgage comparisons, approved negotiations, and final-term checks.
- [Personal-Trading-Desk](projects/Personal-Trading-Desk/) — Paper trading, exposure checks, approvals, and broker reconciliation.
- [Goal-Based-Wealth-Manager](projects/Goal-Based-Wealth-Manager/) — Goal funding, contribution planning, and portfolio rebalancing.
- [Cross-Border-Money-Concierge](projects/Cross-Border-Money-Concierge/) — Remittance comparisons, transfer approvals, and recipient-credit verification.
- [Fraud-Response-Concierge](projects/Fraud-Response-Concierge/) — Lost-wallet response, card protection, charge reports, and recovery.

- [Freelancer-Payday-Agent](projects/Freelancer-Payday-Agent/) — Business cash management, protected reserves, and reviewed personal paydays.
