# Demo

Run permitted paper execution, exposure rejection, and partial-fill/cancellation recovery in isolated temporary databases.

```bash
.venv/bin/python scripts/demo.py
```

The script exercises the implemented domain services with synthetic data. Read [the demo source](https://github.com/vaibhavkapur/Personal-Finance-Agents/blob/main/projects/Personal-Trading-Desk/scripts/demo.py) for the exact setup and assertions.
