# Demo

Run compare-and-deliver, document-request, and accepted-before-timeout transfer recovery in temporary databases.

```bash
.venv/bin/python -m scripts.demo
```

The script exercises the implemented domain services with synthetic data. Read [the demo source](https://github.com/vaibhavkapur/Personal-Finance-Agents/blob/main/projects/Cross-Border-Money-Concierge/scripts/demo.py) for the exact setup and assertions.
