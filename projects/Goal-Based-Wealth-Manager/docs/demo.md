# Demo

Run earlier-goal planning, insufficient funding, and recovery from a partial custodian execution in temporary databases.

```bash
.venv/bin/python scripts/demo.py
```

The script exercises the implemented domain services with synthetic data. Read [the demo source](https://github.com/vaibhavkapur/Personal-Finance-Agents/blob/main/projects/Goal-Based-Wealth-Manager/scripts/demo.py) for the exact setup and assertions.
