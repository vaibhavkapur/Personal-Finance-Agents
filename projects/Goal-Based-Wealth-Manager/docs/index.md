# Goal-Based Wealth Manager

A goal-based wealth-planning prototype that calculates funding gaps, previews contribution and rebalance baskets, binds customer approval to exact actions, and reconciles partial execution against an independent mock custodian.

This repository contains the implemented application, tests, synthetic fixtures, and setup files. It runs against mock providers; the original development plan remains in the local project folder and is excluded from this repository.
