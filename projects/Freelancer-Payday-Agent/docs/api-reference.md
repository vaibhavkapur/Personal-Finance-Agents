# API Reference

The implemented FastAPI schema is served at [http://127.0.0.1:8012/docs](http://127.0.0.1:8012/docs) when the app is running.

Read [the application API contract](api.md) for endpoint semantics, authentication, payloads, and approval flows.

A checked-in [OpenAPI snapshot](openapi.json) is also included; the running server schema reflects the installed code.
